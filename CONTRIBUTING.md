# Contributing

## Generated and hand-written code

The library is a hand-written core plus a resource and model layer generated
from the vendored IR (ADR-0001).

| Path | Origin |
| --- | --- |
| `lib/teachmehipaa/core/`, `lib/teachmehipaa/client.rb`, `lib/teachmehipaa.rb`, `sig/teachmehipaa/core.rbs` | Hand-written |
| `lib/teachmehipaa/models/`, `lib/teachmehipaa/resources/`, `lib/teachmehipaa/{models,resources}.rb`, `sig/teachmehipaa/{models,resources}/` | Generated by `bundle exec rake generate`; do not edit |
| `lib/teachmehipaa/extensions/`, `sig/teachmehipaa/extensions/` | Hand-written methods on generated resources and models (see below) |
| `scripts/generate.rb`, `scripts/generator/` | The generator (standard library only) |
| `openapi/` | Vendored from the monorepo; do not edit (see `openapi/README.md`) |

Every generated file carries a "Generated from openapi/sdk-ir.json - do not
edit" banner. To change generated code, change the generator, or fix the IR
upstream in the monorepo's `tooling/sdk-ir` and re-vendor it.

### Hand-written methods on a resource

A resource listed in `EXTENDED_RESOURCES` (`scripts/generator/resources.rb`)
is generated as `<Name>Base`, such as `Resources::EventsBase`.
`lib/teachmehipaa/extensions/<file>.rb` subclasses it under the plain name
the client exposes (`Resources::Events`, adding `events.tail`), and
`sig/teachmehipaa/extensions/<file>.rbs` signs it. The generated
`resources.rb` requires the extension; `rake generate` refuses to run if
either file is missing. Add any new public method to the generated-surface
test's `HAND_WRITTEN_METHODS`.

### Hand-written methods on a model

A model listed in `EXTENDED_MODELS` (`scripts/generator/models.rb`) works the
same way: `Operation` is generated as `OperationBase`, and
`lib/teachmehipaa/extensions/operation.rb` subclasses it as `Operation`
(adding `wait` and `export_result`); every generated reference to the type
means the subclass. The generated `models.rb` requires the extension.

The spec leaves an Operation's `response` untyped. Methods whose Operations
settle with a known shape are listed in `OPERATION_MODELS`
(`scripts/generator/api_method.rb`) and return an `Operation` subclass that
reads it, such as `WebhookDeliveryOperation` for `webhook_subscriptions.test`
and `.redrive`.

## Regenerating

1. Copy `openapi.developer.json`, `sdk-ir.json` and `sdk-ir.schema.json` from
   one IR build into `openapi/`, and its `source.release` into
   `OPENAPI_VERSION`.
2. Run `bundle exec rake generate`. It checks the IR against its schema, then
   rewrites the generated files, deleting ones the IR no longer produces.
3. Run `bundle exec rake`. The generated-surface test fails if the committed
   output differs from what the generator writes, or if any spec operation
   lacks exactly one public method.
